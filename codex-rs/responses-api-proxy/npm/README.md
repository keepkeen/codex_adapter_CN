# @keepkeen/codex-cn-responses-api-proxy

<p align="center"><code>npm i -g @keepkeen/codex-cn-responses-api-proxy</code> to install <code>codex-cn-responses-api-proxy</code></p>

This package distributes the prebuilt [codex-cn Responses API proxy binary](https://github.com/keepkeen/codex_adapter_CN/tree/main/codex-rs/responses-api-proxy) for macOS, Linux, and Windows.

To see available options, run:

```
codex-cn-responses-api-proxy --help
```

Refer to [`codex-rs/responses-api-proxy/README.md`](https://github.com/keepkeen/codex_adapter_CN/blob/main/codex-rs/responses-api-proxy/README.md) for detailed documentation.
